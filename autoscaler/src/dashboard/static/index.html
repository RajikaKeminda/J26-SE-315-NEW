How to read this

The research claim, made visible.
The agent reads the service dependency graph (SDG) and the live latency graph (EHG), then picks, per service, a replica change (−3…+3) and a CPU/memory size. The SLO objective is p95 end-to-end latency, cost is provisioned CPU + priced memory against a cluster budget, balance is the spread of CPU utilisation. Switch controller above to watch HPA / VPA / threshold rules handle the same traffic.
